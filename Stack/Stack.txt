** Stack Introduction
------------------------

-> A Stack is a special type of data structure that follows the principle of LIFO (Last In, First Out). That means the last element you push onto the stack is the first one you pop out.


    * Real Life Examples
    -----------------------

    1) Books
    2) Carrom / Coins
    3) Stones


    * Operations
    --------------

    1) push(element) → Add an element to the top of the stack.  -> O(1)

    2) pop() → Remove the top element from the stack.           -> O(1)

    3) peek() → Look at the top element without removing it.    -> O(1)

    4) isEmpty() → Check if the stack is empty.                 -> O(1)

    5) size() → Get the number of elements in the stack.        -> O(1)


    * Implementation
    ------------------

        1) Stack Implementation Using Array
        ------------------------------------

        -> Fixed Size: You must define the capacity at creation. If the stack grows beyond that, you hit Stack Overflow.

        -> No Dynamic Resizing: Unlike ArrayList or LinkedList, arrays don’t resize automatically.

        -> Wasted Space: If you allocate a large array but use only a few elements, memory is wasted.

        -> Less Flexible: Managing resizing manually is error-prone compared to using ArrayList or LinkedList.

        -> That’s why in real-world Java applications, developers prefer ArrayList or LinkedList (or simply use the built-in Stack class in java.util) because they handle resizing and memory management internally.
