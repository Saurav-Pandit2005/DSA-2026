** Introduction to Binary Trees
-----------------------------------

-> Binary Tree : Hierarchical Data Structure

-> A binary tree is a hierarchical data structure where each node has at most two children, commonly referred to as the left child and right child.

-------------------------------------------------------------------------------------------------------------

    * Key Terminologies:
    ----------------------

        -> Root: The topmost node.

        -> Leaf: A node with no children.

        -> Parent/Child: Relationship between connected nodes.

        -> Height: Longest path from root to a leaf.

        -> Depth/Level: Distance from root to a node.

--------------------------------------------------------------------------------------------------

** Levels & Subtree in a Tree
---------------------------------

* Levels in a Tree
-----------

-> Level refers to the distance of a node from the root.

-> Root node is always at level 0 OR 1.

-> Its children are at level 1, their children at level 2, and so on.

-> The maximum level in a tree is equal to its height.

-------------------------------------------------

    * Example 
    -------------

                    A (level 0)
                    / \
                B(level 1)   C(level 1)
                / \            \
        (level 2)D E(level 2) F(level 2)

        ------------------------------------

        -> Here:

            -> A is at level 0

            -> B and C are at level 1

            -> D, E, F are at level 2


-> Subtrees in a Tree
-----------------------

-> Left & Right Subtree .....

->A subtree is simply a tree formed from any node and all its descendants.

-> Every node in a binary tree can be considered the root of its own subtree.

-> Subtrees are important because many algorithms (like recursion in traversals, insertion, deletion) work by breaking the tree into smaller subtrees.

-----------------------------------------------------------------------------------------------------------------------------

    * Example:
    ------------

    -> In the above tree:

    -> The subtree rooted at B includes nodes B, D, and E.

    -> The subtree rooted at C includes nodes C and F.

** Build Tree Preorder
-------------------------

->  build the binary tree from the preorder input given.

--------------------------------------------------------

    Input :    1 2 4 -1 -1 5 -1 -1 3 -1 6 -1 -1

    -> Here, -1 represents a null (no child).

    --------------------------------------------------------

    * Step-by-Step Construction
    -----------------------------

    1. Start with 1 → root node.

    2. Next is 2 → left child of 1.

    3. Next is 4 → left child of 2.

        -> After 4, we see -1 -1 → means 4 has no left or right child.

    4. Next is 5 → right child of 2.

        -> After 5, -1 -1 → means 5 has no children.

    5. Next is 3 → right child of 1.

        -> After 3, -1 → means 3 has no left child.

    6. Next is 6 → right child of 3.

        -> After 6, -1 -1 → means 6 has no children.

    -------------------------------------------------------------

    * Final Tree Structure
    -------------------------

        1
       / \
      2   3
     / \    \
    4   5    6

----------------------------------------------------------------------------------------

** Build Tree Preorder Code
--------------------------------

    // Build Tree Preorder Code

    package Binary_Trees;

    public class Binary_Trees_Basics {

        static class Node {
            int data;
            Node left;
            Node right;

            Node(int data) {
                this.data = data;
                this.left = null;
                this.right = null;
            }
        }

        static class BinaryTree {
            static int idx = -1;
            public static Node buildTree(int nodes[]) {
                idx++;
                if(nodes[idx] == -1) {
                    return null;
                }

                Node newNode = new Node(nodes[idx]);
                newNode.left = buildTree(nodes);
                newNode.right = buildTree(nodes);

                return newNode;
            }
        }

        public static void main(String[] args) {
            int nodes[] = {1, 2, -1, -1, 5, -1, -1, 3, -1, 6, -1, -1};

            // Build Tree Preorder function

            BinaryTree tree = new BinaryTree();
            Node root = tree.buildTree(nodes);
            System.out.println(root.data);     
        }
    }
