What is Linked List?
----------------------

-> A LinkedList in Java is a data structure from the Java Collections Framework that stores elements as nodes in a doubly linked list, making insertions and deletions faster than ArrayList, especially in the middle or beginning of the list. 

-> It is part of java.util and implements both the List and Deque interfaces.

----------------------------------------------------------------------------------------------------------------------

** Head & Tail in LinkedList
---------------------------------

-> In a Linked List, the terms Head and Tail refer to the special nodes that mark the beginning and end of the list:


    * Head
    ----------

        -> The Head is the first node of the linked list.

        -> It acts as the entry point to the list — without the head, you cannot traverse the list.

        -> In Java’s LinkedList class, the head is managed internally, but conceptually it points to the first element.

        -> Example: If the list is [10 → 20 → 30], the head points to 10.


    * Tail
    --------

        -> The Tail is the last node of the linked list.

        -> Its next reference is always null (since there’s no node after it).

        -> In a doubly linked list (like Java’s LinkedList), the tail also has a prev pointer to the second-last node.

        -> Example: In [10 → 20 → 30], the tail points to 30.

------------------------------------------------------------------------------------------------------------------------------

** Add First in LinkedList
----------------------------

-> There are three steps for Add First in LL.

    1) Create New node
    2) New Node next -> head
    3) head = new Node

    * Example
    -----------

        // step1 - create new node
        Node newNode = new Node(data);

        if(head == null) {
            head = tail = newNode;
            return;
        }


        // step2 - newNode next = head
        newNode.next = head; // link

        // step3 - head = newNode
        head = newNode;

    * Extra Points for help to Understanding the Problem...
    ----------------------------------------------------------

    -> newNode.next = head; ensures the new node points to the old first node.

    -> head = newNode; updates the head reference to the new node.

    -> Time complexity: O(1) (constant time insertion at the beginning).

----------------------------------------------------------------------------------------------------


** Add Last in LinkedList
----------------------------

-> There are three steps for Add Last in LL.

    1) Create New node
    2) tail next -> newNode
    3) tail = new Node

    * Example
    -----------

         // step1 - create newNode
        Node newNode = new Node(data);

        if(head == null) {
            head = tail = newNode;
            return;
        }

        // step2 - tail.next = newNode
        tail.next = newNode;

        // step3 - tail = newNode
        tail = newNode;

    -> Time complexity: O(1) (constant time insertion at the end).

----------------------------------------------------------------------------------------------------

** Print a Linked List
-------------------------

-> Start from head and move through each node using temp = temp.next.

-> Print the data of each node until you reach null.

-> This traversal is O(n) since you visit every node once.


    * Example
    -----------

     public void print() {

        if(head == null) {
            System.out.println("Linked List is Empty");
            return;
        }

        Node temp = head;
        while(temp != null) {
            System.out.print(temp.data + "->");
            temp = temp.next;
        }
        System.out.println("null");
    }

** Add in the middle of LinkedList
------------------------------------

    -> Traverse the list until you reach the position where you want to insert.

    -> Create a new node.

    -> Adjust the next pointers so the new node fits between two existing nodes.

    ------------------------------------------------------------------------------

    -> If index == 0, it’s the same as addFirst.

    -> If index == size, it’s the same as addLast.

    -> Time complexity: O(n) (because you may need to traverse up to the middle).

    ----------------------------------------------------------------------------------

    * Example
    -----------

    public void addInMiddle(int idx, int data) {

        if(idx == 0) {
            addFirst(data);
            return;
        }

        Node newNode = new Node(data);
        Node temp = head;
        int i = 0;

        while(i < idx-1) {
            temp = temp.next;
            i++;
        }

        // i = idx - 1

        newNode.next = temp.next;
        temp.next = newNode;
    }

    ---------------------------------------------------------------------
    
    -> Always validate the index.

        if(idx < 0 || idx > size)
            throw new IndexOutOfBoundsException();

** Size of a LinkedList
-------------------------

    -> To find the size of a Linked List in Java, you can either:

    1) Maintain a counter that updates whenever you add or remove nodes (efficient).

    2) Traverse the list and count nodes each time you need the size (simpler, but less efficient).

    ---------------------------------------------------------------------------------------------------

    1) Maintaining a counter → O(1) time to get size.

    2) Traversing each time → O(n) time to get size.

    -> In practice, most implementations (like Java’s built-in LinkedList) maintain a counter internally for efficiency.

** Remove in a LinkedList
---------------------------

    1) Remove first
    -----------------

        -> To remove the first node in a Linked List (LL), you simply update the head pointer to point to the second node (head.next).

        -> head = head.next

        -----------------------------------------------------------------------------------------

        * Example
        ----------

        if(size == 0) {
            System.out.println("ll is Empty");
            return Integer.MIN_VALUE;
        }
        
        else if(size == 1) {
            int value = head.data;
            head = tail = null;
            size = 0;
            return value;
        }

        int value = head.data;
        head = head.next;
        size--;
        return value;

        --------------------------------------------------------

        ->If the list is empty (head == null), handle gracefully.

        -> Otherwise, just move head to head.next.

        -> Time complexity: O(1) (constant time).

    ------------------------------------------------------------------------------------

    2) Remove last
    ---------------

        -> To remove the last node in a Linked List (LL), you need to traverse until you reach the second‑last node, then set its next to null.

        -> prev.next = null
        -> tail = prev

        ------------------------------------------------------------------------------------

        * Example
        -----------

        if(size == 0) {
            System.out.println("ll is Empty");
            return Integer.MIN_VALUE;
        }
        
        else if(size == 1) {
            int value = head.data;
            head = tail = null;
            size = 0;
            return value;
        }

        // prev node = i = size - 2
        Node prev = head;
        for(int i=0; i<size-2; i++) {
            prev = prev.next;
        }

        int value = prev.next.data;     // tail.data
        prev.next = null;
        tail = prev;
        size--;
        return value;

        ------------------------------------------------------------------------

        -> If the list is empty → handle gracefully.

        -> If only one node → set head = null.

        -> Otherwise, traverse until temp.next.next == null (second‑last node).

        -> Time complexity: O(n) (linear traversal).
