** Introduction to Queue
---------------------------

-> A Queue is a collection designed to hold elements before processing, typically following the FIFO (First-In-First-Out) principle, 
   though variations like PriorityQueue or Deque allow different ordering.


    * Operations
    --------------

    -> Add  O(1)        => Enque

    -> Remove  O(1)     => Dequeue

    ->Peek()   O(1)     => Front


    * Implementation
    ------------------

        1) Queue Implementation Using Arrays
        --------------------------------------

        -> Queue follows FIFO (First-In-First-Out) → first element inserted is the first to be removed.

        -> Using an array, we need to manage:

        -> front → index of the first element.

        -> rear → index of the last element.

        -> size → number of elements.

        -> We must handle overflow (when queue is full) and underflow (when queue is empty).


        * Why Circular Array?
        -----------------------

        -> Without circular logic, once rear reaches the end, you can’t reuse freed space at the front.

        -> Using (index + 1) % capacity makes the array circular, so space is reused efficiently. 


        * Summary
        ------------

        -> Array Queue is simple but has fixed capacity.

        -> Circular Array Queue solves wasted space problem.

        -> For dynamic resizing, prefer ArrayList or LinkedList implementations.

        2) Circular Queue Implementation Using Arrays
        -----------------------------------------------

        -> In a linear array queue, once rear reaches the end, you can’t insert more elements even if there’s free space at the front.

        -> A circular queue reuses that space by wrapping around using modulo arithmetic.

        -> This makes it more memory-efficient.

        * Summary
        -----------

        -> Circular Queue is array-based but space-efficient.

        -> Uses modulo arithmetic to wrap around indices.

        -> Commonly used in buffering, scheduling, and resource management.

        3) Queue Implementation Using LinkedList
        ------------------------------------------

        * Why LinkedList for Queue?
        -----------------------------

        -> Dynamic size → grows/shrinks as needed.

        -> Efficient insertions/deletions at both ends.

        -> No need for circular logic like arrays.

        -> Java’s LinkedList already implements the Queue interface, so it’s straightforward.

        ----------------------------------------------------------------------------------------

        * Summary:
        -------------

        -> Use Array Queue when size is known and memory overhead matters.

        -> Use LinkedList Queue when dynamic resizing and frequent insertions/deletions are needed.

        4) Queue Implementation Using Java Collection Framework (JCF)
        --------------------------------------------------------------

        ->  Implement a Queue using the Java Collection Framework (JCF). This is the most practical way to use queues in real-world applications because JCF
            provides ready-made, efficient implementations.

        -------------------------------------------------------------------------------------------------------------------------------------------------

        * Key Points
        --------------
                
        -> In JCF, Queue is an interface in java.util.

        * Common implementations:

        -> LinkedList → simple FIFO queue.

        -> PriorityQueue → orders elements by priority.

        ->ArrayDeque → efficient double-ended queue.

        -> Methods available: add(), offer(), remove(), poll(), peek(), element().

        -----------------------------------------------------------------------------------

        *  Summary:
        --------------

        -> JCF makes queue implementation easy and efficient.

        -> Choose LinkedList for basic FIFO, ArrayDeque for performance, and PriorityQueue for priority-based tasks.
